📋 CÁC FILE ĐÃ TẠO:

1. ✅ JpaRegisteredClientRepository.java (Services/)
   - Bridge giữa database và Spring Security OAuth2
   - Convert Oauth2Clients Entity ↔ RegisteredClient
   - Load clients từ DB

2. ✅ AuthorizationServerConfig.java (Config/)
   - Cấu hình OAuth2 Authorization Server
   - Tạo RSA key pair cho JWT signing
   - Định nghĩa OAuth2 endpoints

3. ✅ Oauth2ClientInitializer.java (Services/Impl/)
   - Tự động tạo client mẫu khi start
   - Client ID: my-client-app
   - Client Secret: my-client-secret

4. ✅ CustomUserDetailsService.java (Services/Impl/)
   - Load user từ Customers table
   - Dùng cho OAuth2 authentication

5. ✅ Oauth2ClientsService.java (Services/)
   - Service interface cho OAuth2 clients management

6. ✅ Oauth2ClientsServiceImpl.java (Services/Impl/)
   - Implementation với Mapper pattern
   - CRUD operations cho OAuth2 clients

7. ✅ Oauth2ClientsController.java (Controllers/)
   - REST API để quản lý clients
   - ADMIN only với @PreAuthorize

8. ✅ OAuth2TestController.java (Controllers/)
   - Test endpoints: /api/oauth2/health, /api/oauth2/test-token

9. ✅ SecurityConfig.java (Updated)
   - Thêm @Order(2) và @EnableMethodSecurity

10. ✅ application.properties (Updated)
    - Thêm OAuth2 issuer URL và logging

🔐 TEST AUTHORIZATION CODE FLOW:
═══════════════════════════════════════════════════════════════════════════════

BƯỚC 1: Request Authorization Code (Browser)
http://localhost:8080/oauth2/authorize?response_type=code&client_id=my-client-app&redirect_uri=http://localhost:3000/callback&scope=read%20write%20openid

BƯỚC 2: Login → Approve → Nhận code từ URL redirect

BƯỚC 3: Exchange code for token (Postman)
POST http://localhost:8080/oauth2/token
Headers:
  Content-Type: application/x-www-form-urlencoded
  Authorization: Basic bXktY2xpZW50LWFwcDpteS1jbGllbnQtc2VjcmV0
Body:
  grant_type=authorization_code
  code={YOUR_CODE}
  redirect_uri=http://localhost:3000/callback

Response:
{
  "access_token": "eyJraWQiOiI...",
  "refresh_token": "eyJraWQiOiI...",
  "scope": "read write openid",
  "token_type": "Bearer",
  "expires_in": 3600
}

═══════════════════════════════════════════════════════════════════════════════
🔧 QUẢN LÝ CLIENTS (ADMIN):
═══════════════════════════════════════════════════════════════════════════════

1. Lấy danh sách clients:
   GET http://localhost:8080/api/oauth2-clients
   Headers: Authorization: Bearer {ADMIN_TOKEN}

2. Tạo client mới:
   POST http://localhost:8080/api/oauth2-clients
   Headers: 
     Authorization: Bearer {ADMIN_TOKEN}
     Content-Type: application/json
   Body:
   {
     "clientId": "new-app",
     "clientSecret": "secret123",
     "clientName": "New Application",
     "redirectUris": "http://localhost:3000/callback",
     "scopes": "read,write,openid",
     "authorizationGrantTypes": "authorization_code,refresh_token",
     "clientAuthenticationMethods": "client_secret_basic",
     "accessTokenValiditySeconds": 3600,
     "refreshTokenValiditySeconds": 86400
   }

3. Cập nhật client:
   PUT http://localhost:8080/api/oauth2-clients/{clientId}

4. Xóa client:
   DELETE http://localhost:8080/api/oauth2-clients/{clientId}

💡 KIẾN TRÚC:
═══════════════════════════════════════════════════════════════════════════════

CLIENT REQUEST → AuthorizationServerConfig
                ↓
         JpaRegisteredClientRepository (Load client từ DB)
                ↓
         CustomUserDetailsService (Load user từ DB)
                ↓
         Generate & return JWT tokens

ADMIN QUẢN LÝ → Oauth2ClientsController (@PreAuthorize ADMIN)
                ↓
         Oauth2ClientsService (Business logic)
                ↓
         Oauth2ClientsMapper (Entity ↔ Dto)
                ↓
         Oauth2ClientsRepository (Database)
